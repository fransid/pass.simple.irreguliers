Consigne : conjugue le verbe entre parenthèses au passé simple, à la personne indiquée. Les verbes du 3e groupe présentent plusieurs séries de terminaisons : sois attentif aux radicaux !

Corrigé et explications

Au passé simple, les verbes du 3e groupe suivent plusieurs modèles :

  • -is, -is, -it, -îmes, -îtes, -irent : prendre → je pris ; mettre → ils mirent.
  • -us, -us, -ut, -ûmes, -ûtes, -urent : pouvoir → je pus ; croire → ils crurent.
  • -ins, -ins, -int, -înmes, -întes, -inrent : venir → je vins ; tenir → ils tinrent.
  • -us / -us / -ut avec un radical particulier : être → je fus, avoir → j'eus, savoir → je sus.
  • Cas particuliers : faire → je fis ; naître → il naquit ; mourir → elle mourut ; ouvrir → j'ouvris.

Astuce : mémorise la 3e personne du singulier (il/elle/on) : elle permet souvent de retrouver toute la série.
